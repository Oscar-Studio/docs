# 五子棋

弈室是一间安静的五子棋棋室：可以与朋友同屏对弈、挑战经过自我博弈训练的 AI，也可以观看 AI 执黑白双方对局。

## 三种模式

通过顶部三档切换按钮选择模式。**切换模式会重新开局**。

| 模式 | 玩法 |
|---|---|
| 玩家对战 | 同一设备上，黑白双方轮流落子，无需下载模型 |
| 对战 AI | 默认模式，与自训练 AI 对弈；选择「下一局执子」后点击「重新开局」，即可切换先后手 |
| 观战 AI | AI 执黑白双方自动对弈，可暂停、继续；悔棋后保持暂停 |

## 按需下载模型

打开页面和切换模式均不会自动下载。选择「对战 AI」或「观战 AI」后，点击右侧棋局状态区的 **下载模型**，再等待推理引擎和棋手模型加载完成（合计约 28 MB）。下载完成后，对战模式即可落子，观战模式会自动开始。

同一页面内切换模式无需重复加载。刷新后仍需点击下载按钮，资源缓存由浏览器管理。AI 在你的设备本地思考，无需登录。

## 旧设备兼容

AI 需要浏览器支持 WebAssembly SIMD。若旧 iPad 不支持，页面会在下载前显示说明；可尝试更新 iPadOS，或使用无需模型的「玩家对战」。当前推理引擎没有提供非 SIMD 版本。

缺少 `crypto.subtle` 时，页面会使用 JavaScript 实现的 SHA-256 校验下载文件。

## 规则与操作

- **15×15 棋盘，黑先白后，无禁手**；横、竖、斜任意方向连续五子及以上即获胜。
- 桌面端点击交叉点落子；也可用方向键选择落点，按 Enter 或空格确认。
- 手机端先点击交叉点预览，再点击「确认落子」。
- 最新一手以红点标记，获胜时高亮连线；可开启「显示手数」。
- **悔棋**：玩家对战撤回一手；对战 AI 回到你的回合；观战撤回一手并暂停。
- **思考档位**：快棋 64 次搜索、标准 128 次搜索、深思 512 次搜索。手机上深思可能需要较长时间。
- 棋谱自动保存在本机，也可以导出 JSON 棋谱。
