# 五子棋

弈室是一间安静的五子棋棋室：可以与朋友同屏对弈、挑战经过自我博弈训练的 AI，也可以观看 AI 执黑白双方对局。

## 三种模式

通过顶部三档切换按钮选择模式。**切换模式会重新开局**。

| 模式 | 玩法 |
|---|---|
| 玩家对战 | 同一设备上，黑白双方轮流落子，无需下载模型 |
| 对战 AI | 默认模式，与自训练 AI 对弈；选择「下一局执子」后点击「重新开局」，即可切换先后手 |
| 观战 AI | AI 执黑白双方自动对弈，可暂停、继续；悔棋后保持暂停 |

## 按需下载模型

打开页面和切换模式均不会自动下载。选择「对战 AI」或「观战 AI」后，点击右侧棋局状态区的加载按钮，再等待推理引擎和棋手模型加载完成（CPU 模式合计约 14 MB，GPU 模式约 28 MB）。下载完成后，对战模式即可落子，观战模式会自动开始。

首次下载后，模型与引擎通过 SHA-256 校验并保存到浏览器的 Cache Storage。刷新后点击加载按钮，会优先校验并读取本地缓存，不再重复下载大文件；小型版本清单和页面脚本仍可能联网读取。

按钮会根据当前模型和所选引擎的缓存状态变化：未缓存时显示「下载模型」，部分缓存时显示「下载缺失文件」，两者均已缓存时显示「从本地加载」。新的纯 CPU 引擎也包含在缓存检测和持久保存中。状态检查只读取缓存条目和小型版本清单，完整性校验在点击加载时进行。

文件版本变化或缓存损坏时，会下载对应的新文件并替换旧缓存。浏览器禁用存储、空间不足或主动清理网站数据时，仍能联网运行，但之后可能需要重新下载。同一页面内切换模式继续复用已加载的棋手。AI 在你的设备本地思考，无需登录。

## 旧设备兼容

AI 需要浏览器支持 WebAssembly SIMD。若旧 iPad 不支持，页面会在下载前显示说明；可尝试更新 iPadOS，或使用无需模型的「玩家对战」。当前推理引擎没有提供非 SIMD 版本。

加载时会检测 GPU 是否实际可用，再自动选择引擎。GPU 不可用、仅有软件适配器或探测超时时，使用更轻的纯 CPU 引擎；浏览器明确报告内存不超过 2 GB 时，也会保守选择 CPU。没有内存信息时照常检测 GPU，不按浏览器品牌一刀切。

GPU 初始化或运行失败时，会自动保留棋谱、重建运行环境并切换到 CPU 重试；同一标签页会记住回退结果，刷新后继续使用 CPU。普通下载失败不会触发无效切换。不同引擎首次使用时需要分别下载，模型缓存仍可复用。

若出现「加载时内存不足」，可先关闭其他标签页再重试。内存优化不能保证所有设备都能运行，持续失败时可使用玩家对战或其他设备。

缺少 `crypto.subtle` 时仍可使用 JavaScript SHA-256 校验。大文件缓存校验也使用 JavaScript 实现，以减少内存副本。

## 规则与操作

- **15×15 棋盘，黑先白后，无禁手**；横、竖、斜任意方向连续五子及以上即获胜。
- 桌面端点击交叉点落子；也可用方向键选择落点，按 Enter 或空格确认。
- 手机端先点击交叉点预览，再点击「确认落子」。
- 最新一手以红点标记，获胜时高亮连线；可开启「显示手数」。
- **悔棋**：玩家对战撤回一手；对战 AI 回到你的回合；观战撤回一手并暂停。
- **思考档位**：快棋 64 次搜索、标准 128 次搜索、深思 512 次搜索。手机上深思可能需要较长时间。
- 棋谱自动保存在本机，也可以导出 JSON 棋谱。
