# 2048

经典滑动合并数字游戏——相同数字相撞会合并成它们的和，每次移动后随机生成一个 **2** 或 **4**，目标：拼出 **2048**！

## 玩法说明

- **方向键** 或 **滑动屏幕** 移动所有数字方块
- 相同数字相撞会合并成它们的和
- 每次移动后随机生成一个 **2** 或 **4**
- 目标：拼出 **2048**！

## 特点

- 简洁优雅的视觉设计
- 流畅的滑动动画
- 分数记录与本地存储
- 全站 TOP 30 排行榜（登录用户参与）
- 随时重新开始

## 排行榜

侧栏有两个标签页：「我的记录」是保存在当前浏览器的 TOP 10 本机成绩，「全站 TOP 30」是登录用户的云端最高分排名，两套数据互不影响。

- 每位用户只保留**历史最高分**；游戏结束和中途弃局都会上报，服务端取较大值
- 未登录也能正常游戏，成绩会先暂存，登录后自动补报
- 登录用户即使不在前 30 名，也能在面板顶部看到自己的名次；自己的上榜行会高亮
- 排行榜服务不可用时只在该面板提示，游戏与本地记录不受影响

| 右移 | `→` 或 `D` | 手指右滑 |

## 进阶技巧

- **保持最大数字在角落** — 固定一个角落（如左下）累积最大数字
- **避免过早填满棋盘** — 合并比新增更重要
- **观察下一格** — 提前规划下一格可放置的位置
- **链式合并** — 一次移动触发多次合并可获得更高分数

## 技术实现

- **纯静态** — HTML + CSS + 原生 JavaScript，无任何依赖
- **流畅动画** — CSS `transform` + `transition` 实现方块移动与合并
- **本地存储** — 最高分持久化在 `localStorage`
- **云端榜单** — 共享登录 + MySQL 存储每位用户的最高分，前 30 名公开可读
- **响应式** — 桌面与移动端统一体验，触屏滑动支持
