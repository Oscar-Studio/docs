# 心算记忆

屏幕显示一个算式，**第一轮只需心算答案并记住**。从第 `level+1` 轮起，每轮额外要求你输入 `level` 轮前的答案。算式复杂度随轮次递增：**一位数± → 两位数± → 一位数× → 混合×±**。答错即结束，按级别分别记录历史最佳。

## 玩法

- **10 级难度**（1-10）：等级 = 需要回忆多少**轮前**的答案
- 每一轮显示一个算式（无输入框），心算答案并记住
- 从第 `level + 1` 轮起，每轮额外出现输入框要求输入 `level` 轮前的答案
- 答错游戏结束；每级独立历史最佳成绩，存 localStorage
- **不揭示当前轮的答案**——所有反馈都通过后续轮次的回忆题来验证

## 算式曲线

| 轮次 | 算式类型 | 示例 | 结果范围 |
|---|---|---|---|
| 1-5 | 一位数 ±（结果非负） | `7 + 2` · `5 − 3` | 0-18 |
| 6-10 | 两位数 ±（结果非负） | `37 + 18` · `42 − 15` | 5-80 |
| 11-15 | 一位数 × | `4 × 7` · `9 × 6` | 4-81 |
| 16+ | 一位数 × ± 一位数（结果非负） | `5 × 7 + 13` · `6 × 8 − 21` | 1-161 |

**关键约束**：所有算式结果保证非负 — 减法总是大减小；混合运算保证乘积 ≥ 减项。

## 等级体验

| 等级 | 典型体验 |
|---|---|
| 1 级 | 一直是一位数 ±，只记前 1 轮，节奏快 |
| 3 级 | 算式从一位数 ± 滚动到两位数 ±，需要记前 3 轮 |
| 5 级 | 算式多样，记忆窗口适中 |
| 10 级 | 第 11 轮就要回忆第 1 轮（一位数 ±），第 30 轮要回忆第 20 轮（混合运算）— 心算 + 工作记忆双重压力 |

## 操作

| 操作 | 桌面端 | 移动端 |
|---|---|---|
| 拼答案 | 直接敲数字键 / `Backspace` 删除 / `Esc` 清空 / `Enter` 提交 | 点击 0-9 数字键 · ⌫ 退格 · C 清除 |
| 进入下一题 | `下一题` 按钮 / `Enter` | `下一题` 按钮 |

数字键盘按钮高 60px（移动端 52px），大触控目标，方便单手操作。

## 视觉设计

- **深海军回顾面板** `#181715` 在失败结算页单独成段（cream → dark 节奏）

- 无阴影，靠色块对比分层

## 反馈设计

- 答对时输入框变绿色 + 反馈行显示 `✓ 答案正确`，350ms 后进入下一题
- 答错时输入框变红色 + 反馈行显示正确答案，950ms 后跳转到结算页
- **永远不揭示当前轮算式的答案**——你只通过后续回忆题"间接"知道自己这一轮算对了

## 技术实现

- **纯静态** — 单文件 HTML + CSS + 原生 JavaScript，无任何依赖
- **离线可用** — 关闭网络也能玩（字体通过 Google Fonts CDN，预加载可断网时使用 fallback）
- **状态持久化** — localStorage 按级别存历史最佳
- **响应式** — 桌面与移动端统一布局，键盘输入与触摸输入双通道
- **生成式题库** — 每次开局随机，无重复
