# 技能五子棋

增强版五子棋——保留五子连珠的获胜规则，但每方拥有**能量条**与 5 种强大技能，可在对局中发动以干扰对手。**当一方连成 5 子时，若对手仍有能量反制，对局继续**——这是与普通五子棋最大的区别。

## 玩法说明

- **黑方先手**——双方轮流落子（同普通五子棋）
- 每方拥有**能量条**（上限 100），每秒钟为对手 +1 能量
- 落子可发动技能消耗自身能量，技能按钮悬停查看效果说明
- 任意方向先连成 5 子**且对手能量不足以发动 `飞沙走石`（15）**时即获胜
- 完整操作日志实时显示在棋盘下方

## 特点

- 5 种强力技能：**飞沙走石**、**力拔山兮**、**静如止水**、**时光倒流**、**两级反转**
- 实时能量条 + 技能按钮显示当前可用状态
- 五子连珠可被对手技能反制，需要更多策略与资源管理
- 完整操作日志（按时间戳记录所有操作）
- 历史回溯最多保存 20 步状态

## 操作

| 操作 | 桌面端 | 移动端 |
|---|---|---|
| 落子 | 鼠标点击棋盘交叉点 | 手指点击 |
| 发动技能 | 点击对应技能按钮 | 按钮点击 |
| 重新开始 | `重新开始` 按钮 | 按钮 |

## 技能列表

| 技能 | 消耗 | 效果 |
|---|---|---|
| 飞沙走石 | 15 | 移除对手一颗棋子，然后自己再下一颗子 |
| 力拔山兮 | 25 | 在棋盘砸出 3×3 大坑，清除区域内所有棋子，对手下一回合无法在坑内落子 |
| 静如止水 | 35 | 冻结对手下一回合（对手跳过），自己连下两颗子 |
| 时光倒流 | 50 | 回溯到上回合落子前的状态，并可再下一颗子 |
| 两级反转 | 50 | 与对手交换棋盘状态、能量、颜色、阵营 |

- **限制规则** — 飞沙走石 / 力拔山兮 / 静如止水 每回合最多用 1 个；时光倒流 / 两级反转 不能与其他技能同回合连用
- **能量策略** — 发动技能消耗自身能量，对手每秒 +1，能量是核心博弈资源

## 与普通五子棋的区别

| 维度 | 普通五子棋 | 技能五子棋 |
|---|---|---|
| 规则 | 5 子即胜 | 5 子且对手无 15 能量反制即胜 |
| 互动 | 纯棋艺对抗 | 可主动干扰对手 |
| 资源管理 | 无 | 能量条 + 技能冷却 |
| 心理博弈 | 推算对手走法 | 推算 + 隐藏技能意图 |
| 变数 | 较少 | 极大，每局都不一样 |

## 技术实现

- **纯静态** — HTML + CSS + Canvas + 原生 JavaScript，无任何依赖
- **Canvas 渲染** — 棋盘网格、星位、棋子、破坏区域、最后一手标记
- **状态栈** — 最多保存 20 步历史状态，支持 `时光倒流` 回溯
- **能量系统** — `setInterval` 每秒为对手 +1 能量
- **粒子效果** — 玩家面板使用毛玻璃与渐变色
