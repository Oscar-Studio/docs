# 军棋

[打开军棋棋桌](https://games.oscarstudio.cn/军棋/)，选择玩法后挑战电脑，或创建好友房。对手可以通过邀请链接或六位房间码入座，游客也能玩。

## 布阵暗棋

双方各执 25 枚棋子。可以直接使用开局阵型，也可以在准备前点两枚己子交换位置。军旗放在己方大本营，三枚地雷限后两排，炸弹避开首排，行营留空。入大本营的棋子不能再移动。

你能看见己方身份。交战后，棋谱会记录谁留在原地、谁被移除；一方司令阵亡，该方军旗亮出。攻入敌旗所在位置即可获胜。

## 翻棋

双方轮流翻子或走明子，第一次翻出的颜色归先手。暗子占位，必须先翻开才能攻击。大本营可以通行。先清除对手三枚地雷，再用任一可移动己子夺取已翻开的敌旗；棋桌会显示双方还剩多少地雷。

## 行棋与交战

- 公路一次走一段。铁路可沿直线连续行进，工兵可以沿畅通铁路转弯。点选工兵的远处目标可预览路线，再点一次确认。
- 行营中的棋子免受攻击。军衔从高到低为司令、军长、师长、旅长、团长、营长、连长、排长、工兵。高阶获胜，同级同归于尽。
- 工兵可排雷并存活，炸弹碰雷双方移除，其他普通棋子碰雷阵亡。炸弹与普通棋子交战时双方移除。夺旗按当前玩法的夺旗规则结算。
- 无合法行动判负，翻棋中仍可翻子就能继续。双方可求和，满 600 手自动和棋。结算后可逐手复盘、开启全盘揭示，或再战并交换先手。

## 好友房

双方准备后开始。快捷语可问候或请对方稍等；求和需对方回应，认输需本人确认。静音后仍能收到求和与再战请求。

刷新后用原浏览器打开邀请链接即可回到自己的席位。系统检测到离线后暂停棋局并保留三分钟，逾时对手可领取胜局。房间保存在服务内存中，双方均离开两小时或服务重启后关闭。
