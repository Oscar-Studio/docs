# AI Studio

在 [AI Studio 首页](https://ai.oscarstudio.cn/) 选择对话或语音合成。顶栏可以在两个工作台之间切换，也可以选择浅色、深色或跟随系统。

## Chat 多模型对话

1. 使用 Oscar Studio 账号登录，或从登录页选择访客体验。
2. 在输入区选择模型。支持图片或音频的模型会显示附件按钮，也可将文件拖到输入区。
3. 输入消息后按 Enter 发送，按 Shift+Enter 换行。回答会实时显示，生成时可以点击停止按钮。
4. 在桌面左栏打开历史会话，或在手机上点击对话标题旁的历史按钮。每个会话可以置顶、重命名或删除。

长按输入框或点击最右侧的麦克风开始录音，再点一次麦克风结束。每段录音最长 60 秒，由 MAI Transcribe 2 识别后追加到草稿，可编辑后再发送。

回答支持 Markdown、代码块复制和数学公式。模型返回推理内容时，可以展开查看思考过程。顶栏显示今日剩余积分。1 积分对应 ¥0.001 的模型用量，standard、pro、promax、ultra 每天分别有 100、300、600、1,000 积分。一次对话调用最多输入 20,000 token，上下文最多 100,000 token。模型价格、缓存费用和输入模态见[模型价格与积分](./model-pricing.md)。

## TTS 语音合成

- **预设音色**可选择 MiMo TTS 或 Eleven v4 Turbo。MiMo 支持补充语气、语速或方言。Eleven v4 Turbo 可按名称搜索共享音色、按语言筛选，并试听有样本的结果。
- **声音设计**按文字描述生成声音，例如「语速平稳、声音温和的年轻女性」。
- **音色克隆**使用上传的 MP3 或 WAV 样本，最大支持 10 MB。

输入要朗读的文字，点击「生成语音」。结果可以在页面上试听。MiMo 提供 WAV 下载，Eleven v4 Turbo 提供 MP3 下载。
