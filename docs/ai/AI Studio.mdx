# AI Studio

多厂商 AI 对话客户端——一个面板切换 DeepSeek、MiniMax 等不同厂商的模型，支持文本、图片、音频多模态输入，含深度思考与 TTS 语音合成。

## 核心功能

### 文本对话
- 实时流式响应（token-by-token）
- 多轮上下文记忆
- 深度思考（DeepSeek reasoning）模式可显示思考链
- Markdown / 代码高亮渲染

### 多模态输入
- **图片理解** — 直接拖入或选择图片作为对话内容
- **音频输入** — 上传音频文件，模型可转写与理解
- 多文件批量上传

### TTS 语音合成
- 文本转语音，支持多种音色
- 长文本流式合成
- 可下载音频文件

### 模型与厂商
- **多厂商支持** — DeepSeek、MiniMax（按账号配额）
- 模型自由切换（侧边栏底部 `MODEL` 切换器）
- 厂商 / 模型名清晰标识

## 界面布局

- **顶栏** — Logo + `AI STUDIO` eyebrow + 每日 Credits 配额显示
- **左栏** — Chat / TTS 视图切换
- **底部** — 模型选择器（厂商 + 模型名）
- **主区** — 滚动消息流 + 底部输入面板

## 配额与账号

- 顶栏 `CREDITS` 胶囊显示今日剩余调用额度
- 需登录（复用 Oscar Studio 统一账号体系）
- 不同模型消耗不同 Credits

## 使用步骤

1. 打开 [ai.oscarstudio.cn](https://ai.oscarstudio.cn)
2. 登录 Oscar Studio 账号
3. 左侧选择 `Chat` 或 `TTS` 视图
4. 底部选择厂商 + 模型
5. 输入消息，按 `Enter` 发送（`Shift+Enter` 换行）
6. 等待流式响应；可随时中断

## 技术实现

- **多文件** — `index.html` + `app.js` + `chat.js` + `tts.js` + `user-button.js` + `app.css`
- **字体** — Inter + JetBrains Mono（与本站文档站一致）
- **认证** — 通过 `user-button.js` 集成 Oscar Studio 账号
- **API** — 走 Oscar Studio 后端 `api.oscarstudio.cn`，按账号路由到对应厂商
- **状态管理** — 视图切换 / 模型切换 / 配额刷新均前端处理

## 适用场景

- 日常写作、翻译、总结
- 代码生成与解释
- 复杂问题的深度思考链
- 图片 / 音频内容理解
- TTS 朗读文章 / 校对文稿
