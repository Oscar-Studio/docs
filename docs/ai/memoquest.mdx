# memoquest

**一位会板书的 AI 老师**——它一边讲，一边往黑板上写凝练的重点；讲到关键的地方会停下来问你一句；你答完，它再接着讲。

<Link to="https://memoquest.oscarstudio.cn" className="button button--primary button--lg">打开 memoquest</Link>

## 它和普通 AI 答疑差在哪

所有 AI 答疑工具给的本质是同一样东西：**一篇一次性的结构化长文**。读的时候在跟着走，读完就散——内容进的是短期记忆，几天内衰减；学生全程被动，没有"该想一想"和"该记一下"的分界。

memoquest 的答案不是"讲得更好"，是**换一种讲课形态**：

|  | 演讲稿（下方） | 黑板（上方） |
|---|---|---|
| 内容 | 完整、连贯、口语化的散文 | 凝练的重点、强调项、可交互点 |
| 数量 | 150–280 字，连续 | 关键词最多 5 条 + 1 条结论 + 抽问卡 |
| 作用 | 承载理解与过渡 | 承载记忆锚点与操作 |
| 类比 | 老师说的话 | 老师写在黑板上的字 |

关键：**黑板不是演讲稿的镜像**。老师不会把每句话都写上黑板。黑板是"提纲 + 强调 + 可交互"。

## 三个核心机制

**① 解题思路置顶**
你输入的问题原文原样钉在黑板最上方——不挂学科标签，零成本。

**② 黑板按节奏贴卡**
讲解时，AI 会在讲到重点的地方内联一个标记（`«kw:术语»` / `«num:数值»`），另一个模型负责把标记凝练成卡片。**播放到那一处，卡才贴上来**。一条卡 = 工作记忆里的一个组块。

**③ 讲中抽问**
讲到关键处会**停下来**，黑板上出现一道题。你答完 + 看完解析，才继续往下讲。

> "讲中抽问"比"讲完给两道题"强得多：后者测的是"刚才读过"，前者才是**主动回忆**。

## 怎么用

1. 输入一个你刚做完的题，或一个没听懂的概念
2. 看讲解稿逐句推进，重点会一条条贴到黑板上
3. 被抽问时选一个答案——**选错也没关系**，会直接给你判别依据
4. 讲完可以「↺ 重播本段」

播放控制条在下方：`⏸ 暂停` / `1x 2x 4x` / `↺ 重播本段` / `⏭ 跳过本段`。

追问是支持的——直接接着问"那第二条呢？"，它记得前面讲过什么。

## 几条设计上的取舍

- **不做间隔复习**。产品没有回访抓手，V0 的结论只覆盖"单次体验好不好用"。这不是偷懒，是先把"形态对不对"验证掉。
- **黑板准入规则**是硬闸门：只允许 4 类卡（关键词 / 数字 / 结论 / 抽问），禁止完整句子、解释性段落、超过 12 字的注解。写死这条规则，黑板才不会变成花里胡哨的滚动信息流。
- **判分在本地完成**，不回头调模型。答错直接给解析，不做二次作答——K12 场景下多一轮交互就是摩擦。
- **数据只存在这台设备**（localStorage，20 条上限），不上云。
- **AI 讲错史实是教学事故**，所以提示词里硬性要求：不确定就明说"建议查一下课本"，不编造年代、数字、出处。

## 可以自己选模型

页面上有个「模型」栏，讲解和板书分开选（会记住你的选择）：

| 阶段 | 默认 | 说明 |
|---|---|---|
| **讲解**（写稿） | Qwen3 Next 80B | 🆓 免费，不扣额度 |
| **板书**（编排） | Ling 2.6 Flash | 约 220 credits/次 |

**全部 45 个模型都能选**（20 个免费 + 25 个计费），按"讲解成本"从低到高排，免费的排最前。价格不是写死的，而是每次从服务端拉——后端改价这里立刻跟着变。

选型的时候最重要的一件事是**先看这次要花多少**。每次调整模型，下面都会实时显示：

```
本次问答约 2448 credits · 占今日额度 10% · 当前还剩 18234
```

**如果超过当天剩余额度会直接红字拦下**，并告诉你怎么救（把讲解换回免费模型就行）：

```
本次问答约 49.5k credits · 占今日额度 198% —— 超了，API 会直接拒绝。
把讲解换回免费模型就能讲。
```

这不是吓唬人：真按最贵的组合问一次，一天 25000 的额度就没了。

> 免费模型被上游限流时会自动退避重试两次再放弃。重试**只会重试同一个模型**，不会偷偷换成贵的——那不叫容错叫烧额度。

## 用量说明

走的是 Oscar 账号的 AI 额度，**与 [AI Studio](/ai/AI Studio) 共用同一个额度池**（standard 档 25000 credits/天，pro 50000，promax 100000，ultra 200000）。

默认配置下讲解免费、编排约 220 credits 一次，standard 档一天够问上百次。选了计费的讲解模型会贵不少，但讲解能写得明显更细——按需换，不用一直开着。
