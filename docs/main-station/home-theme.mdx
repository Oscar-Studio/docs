# 主页与个性化背景

[Oscar Studio 主站](https://oscarstudio.cn/)统一使用 Atlas 创意工作室首页。经典主页（Classic）已退役，之前选择过 Classic 的用户也会进入新版，已有背景图片不会因此删除。

## 创意工作室首页

首页以暖白与朱橙、工作台插画和编辑式排版呈现 AI Studio、教学工具、实用工具、益智游戏和 HTML-PPT 五个项目。

- 五个项目快捷入口，以及可按名称、介绍、关键词和分类筛选的工具目录。
- `⌘K` / `Ctrl+K` 聚焦搜索、手机折叠菜单、深浅配色和减少动态效果。
- 工具直接跳转到各子站，共享账号按钮继续使用统一登录。

## 换一张自己的风景

1. 点击首屏右下角「首页背景」或「更换风景」。
2. 在 [UI 设置](https://api.oscarstudio.cn/settings.html) 上传 JPG、PNG、WebP 照片，文件最大 3 MB。上传只添加候选图，不改变当前选择。
3. 回到首页背景面板，选择已上传的候选图或「山间日出」。
4. 按需调整遮罩深度与背景模糊，然后点击「看看效果」。
5. 随时选择「默认画布」恢复插画布局。

图片只出现在首屏，下方工具目录保持实色画布。图片加载失败时回到默认画布。在 UI 设置上传的照片直接保存至腾讯云 COS，遮罩和模糊随账户保存，可在其他设备读取；图片上传与加载不经过 API 服务器。上传照片需要登录。首页只选择背景，不进行上传；恢复默认画布不会删除候选照片。选中照片缓存到当前浏览器，打开首页优先显示本地图片，再后台同步账户选择；本机空间不足时使用 COS 图片地址。

已登录时，首页读取账户保存的背景。历史上仅保存在浏览器的照片暂时保留；如需同步到其他设备，请登录后在 UI 设置重新上传原照片。未登录时，默认画布、预设背景和调整仍保存在本机。

## 各工具集入口

[游戏大厅](https://games.oscarstudio.cn/)、[教学工具集](https://edu.oscarstudio.cn/)、[实用工具集](https://tools.oscarstudio.cn/)也统一使用各自新版入口，取消 Classic 切换，保留深浅配色与关键词搜索。

- 游戏大厅：片头式风景封面与淡紫色标题。
- 教学工具：笔记本纸页、胶带与微倾照片。
- 实用工具：工作台式照片视窗。
- [HTML-PPT](https://ppt.oscarstudio.cn/)：演示封面与独立作品管理区；编辑器不受背景调整影响。

各入口可独立选择本机背景、遮罩和模糊，操作方式与主站相同。
