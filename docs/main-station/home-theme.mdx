# 主页主题

`oscarstudio.cn` 主站支持两套可选主页风格，可在[账号设置](https://api.oscarstudio.cn/settings)页面切换。主题选择保存到账户，并在登录设备间同步。

## Atlas 创意工作室

Atlas 是以中文为主的工具工作室首页，帮助新访客了解 Oscar Studio，也让回访用户快速找到工具。首页用暖白与朱橙色彩、原创 SVG 工作台插画和编辑式排版呈现五个项目：AI Studio、教学工具、实用工具、益智游戏和 HTML-PPT。

- 首屏提供五个项目快捷入口；向下可查看精选工具并搜索完整目录
- 搜索名称、介绍和关键词，并组合 AI、教学、实用工具、游戏和演示文稿分类
- 支持 `⌘K` / `Ctrl+K` 聚焦搜索、手机折叠菜单、`paper/ink` 深浅配色和减少动态效果
- 工具地址直接指向各子站，包含白板的 `/#/whiteboard` 等路由
- 使用共享账号按钮，并按用户设置同步主页主题

Atlas 保留轻量插画和短暂入场效果，不再依赖粒子画布、逐字标题或自定义鼠标指针。选中主题后，Atlas 页面代码按需加载。

## 经典自定义（classic）

经典主页继续提供主站原有的工具介绍布局，并兼容用户自定义背景、遮罩、模糊和背景音乐等设置。切换到 Atlas 时会跳过自定义背景层，切回经典主页后原有设置仍可使用。

## 切换方法

1. 登录后访问 [账号设置](https://api.oscarstudio.cn/settings)。
2. 在「主页主题」中选择 **经典自定义** 或 **Atlas**。
3. 保存设置。

没有显式选择过主题的用户默认使用 Atlas，包括新用户、访客和未设置主页主题的老用户。选择的主题会保存在 `users.ui_config.homeTheme`，并同步到其他登录设备。

## 开发者说明

- 主题选择与默认值由 `API/routes/ui.js` 维护；前端入口位于 `main-station/src/App.tsx`。
- Atlas 保留单独的懒加载子树和 `#atlas-scope` 样式边界，避免影响经典主页。
- Atlas 的 `paper/ink` 偏好储存在本地，和经典主题的全局配色相互独立。
