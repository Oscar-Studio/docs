# 心算记忆加入倒计时

[心算记忆](/games/心算记忆) 现在有倒计时限制——在限定时间内尽量多答对几轮，看看你能坚持多久。

## 时长映射

| 难度 | 时长 |
|---|---|
| 1-3 级 | 60 秒 |
| 4-6 级 | 120 秒 |
| 7-10 级 | 180 秒 |

## 视觉与交互

- 倒计时放在算式卡顶部右侧（左侧是"第 N 轮"），配 🕐 图标 + JetBrains Mono 等宽数字
- **≤30s** 变琥珀色（warning） · **≤10s** 变红色 + 1s 脉冲（critical）
- 时间到走结算页，副标题改为 `"X:XX 用尽，答对 X 轮"`，不显示失败信息（没失败题）
- 答错仍然是提前结束，按原来的格式显示失败信息
- 结算页新增"用时"行展示总耗时
