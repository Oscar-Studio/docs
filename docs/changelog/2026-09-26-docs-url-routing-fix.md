# 媒体播放器重做 + 文档站直链修复

两件事：教学工具的[媒体播放器](/teaching-tools/media-player)做了一次彻底重做，[更新日志](/changelog)、[标签](/tags)、[益智游戏](/games)、[AI](/ai)、[教学工具](/teaching-tools) 这几个文档站章节首页也恢复了直链访问。

## 媒体播放器

教学工具站的媒体播放器（[在线使用](https://edu.oscarstudio.cn/media-player/)）原来有 4 个按钮控制 3 种播放模式、点「网页全屏」没反应、暂停图标显示成一个方框。这次把控件和播放逻辑整体重写了。

### ⚡ 优化

- **一套控件通吃音视频**：原来视频有一套覆盖式控制栏、音频另有一套面板，两套音量/倍速互相打架。现在合并成一套，音频在舞台里显示为带旋转唱片的封面区。
- **播放模式合并成一个按钮**：单曲循环、列表循环、随机播放三个按钮收成一个，单击循环切换 `顺序播放 → 单曲循环 → 列表循环 → 随机播放`，图标、角标、按钮提示同步变化。
- **网页全屏真的能用了**：`T` 或工具栏显示器图标，隐藏标题、列表、快捷键提示，只留画面占满网页。
- **进度条可以按住拖动**了（原来只能点击），时间显示支持超过 1 小时的媒体（`1:30:00` 而不是 `90:00`）。
- 倍速在切歌后保持；列表里音频自动显示时长；当前播放项自动滚动到可见位置；随机模式下「上一首」按播放历史回退，而不是随机跳另一首。
- 播放列表整块面板都是拖拽投放区，拖到面板外不会误触发浏览器直接打开文件；浏览器全屏时控制栏 3 秒无操作自动隐藏。

### 🐛 修复

- **暂停按钮显示成方框**：换图标时代码漏掉了 `fa-solid` 字体族 class，图标退化成正文里的豆腐块（播放/暂停、音量、静音都受影响）。
- **网页全屏点了没反应**：脚本给 `<body>` 加了 `.theater-mode`，但页面上根本没有对应的 CSS 规则。
- **顺序模式播完最后一项会从头无限重播**，现在顺序模式播完即停。
- **浅色主题下「添加文件 / 清空」按钮几乎看不见**：页面用的是一批并不存在的 CSS 变量（`--bg-card`、`--border`、`--secondary` 等），已全部换成 design-tokens 里真实的主题变量，深浅色都跟随。
- 移除/清空列表后播放状态、时间显示、blob URL 残留的问题。
- 快捷键提示里写的 `-` `+` 之前没有生效；焦点在下拉框/滑块上时按方向键会误触发播放器；`M` 静音后图标不更新。
- 移动端没有 hover，控件可能点不到；音频在浏览器全屏里是一大片空白黑屏。

### ⚡ 内置样例音频移除

原页面会预置一段「Oscar 严选」样例音乐（一个 4.5MB 的 mp3，每次打开都要下载一遍），现已连同 mp3 文件一起从站点和代码里移除，播放器只播放你自己添加的文件。

## 🐛 文档站章节首页恢复直链访问

[更新日志](/changelog)、[标签](/tags)、[益智游戏](/games)、[AI](/ai)、[教学工具](/teaching-tools) 这几个章节首页现在可以直接打开、刷新、分享和收藏了。之前它们只在"站内点击"时看起来正常（前端路由不发请求），一旦直接访问 URL 就是 404 或 403。

- **[更新日志首页](/changelog) 404**：服务器上「禁止访问的敏感文件」规则里有一条不区分大小写的 `CHANGELOG` 行尾匹配，把正常的 `/changelog` 页面误判成了敏感文件。已改为精确放行该路径。
- **章节首页 403**：[标签](/tags)、[益智游戏](/games)、[AI](/ai)、[教学工具](/teaching-tools) 这几页在构建产物里同时存在"目录 + 同名 `.html`"（目录只放子页面），URL 兜底规则先去匹配目录，于是跳到 `/xxx/` 之后变成 403。已调整为先命中 `.html`。
- **带尾斜杠的写法也一并兜住**：`/changelog/`、`/tags/`、`/games/`、`/ai/`、`/teaching-tools/`，以及更新日志条目带尾斜杠的形式现在都能正常打开，内容与不带斜杠的规范 URL 完全一致。
- 修复后上述地址全部返回 200；不存在的路径仍然正常返回 404。

> 这一项是部署基础设施（服务器 URL 路由规则）的修复，页面内容本身没有变化。
