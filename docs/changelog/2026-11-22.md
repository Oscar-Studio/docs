[摘词本](/teaching-tools/摘词本)的「我的词库」新增批量导入，可把整理好的词表一次性加进词库，不用逐条录入。

## ✨ 批量导入

- 支持 CSV 与 JSON 两种文件，导入前会先解析并预览可导入的词条数量。
- 弹窗内可直接下载 CSV / JSON 模板，按表头或字段填写即可。
- 自动跳过词库中已存在的词条、文件内重复的词条，以及缺少单词或释义的行。
- 例句相关列（英文例句、整句翻译、挖空内容）可选填，导入后同样支持挖空背诵。
- 文件较大时会自动分批提交，单次导入不再受条数限制。
