游戏大厅新增第 14 个游戏 [霓虹音游](https://games.oscarstudio.cn/neon-pulse/)（[文档](/games/霓虹音游)）——参考 Phigros 玩法的浏览器音游。

## ✨ 新增

- 🎵 [霓虹音游](https://games.oscarstudio.cn/neon-pulse/) 上线（[文档](/games/霓虹音游)）：**音乐全部由内置合成器实时生成**，谱面从同一张音乐事件表派生，所以音画同步是结构性保证，不存在对轴问题，也没有版权问题
  - 2K–12K 任意键数，Phigros 式家用键位；点按 / 长按 / 双押，PERFECT·GREAT·GOOD·MISS 四档判定，严格 / 标准 / 宽松三档窗口，满分 1,000,000 分
  - 内置 3 首曲子：Neon Drive 霓虹夜驰（128 BPM Synthwave）、Crystal Rain 水晶雨落（138 BPM 明快流行）、Void Runner 虚空疾行（148 BPM Dark / DnB），EASY / NORMAL / HARD 三档难度，密度上限是硬保证
  - **手机 / 平板直接用手指点轨道就能玩**：双押用两根手指同时按，滑动可自动换道，判定用硬件时间戳不吃帧延迟的亏
  - **可导入自己的歌**：设置页导入本地音频（mp3 / wav / ogg / m4a 等），自动做节拍检测并扒出谱面
  - **延迟校准**：跟着节拍敲 20 次空格即可测出你实际感知到的音频延迟并补偿
  - 下落速度 0.4×–2.2×、背景亮度与泛光可调（低配可关），切后台自动暂停，成绩按歌曲 + 难度 + 键数分别记录
