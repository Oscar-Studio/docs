# 2026-10-14 · 教学工具集新增「电路画板」

✨ 教学工具集新增[电路画板](https://edu.oscarstudio.cn/电路画板/index.html)：初中物理「电路」单元的作图工具，**实物图和电路图不是两份独立的数据，而是同一份电路连关系的两种投影**，所以两者可以无损地来回转换，反复转也不会累积误差。

## ✨ 新增

- **一键互转**：实物图 ⇄ 电路图。转换不是图像转换，而是换渲染器 + 重新排布，连接关系永远保持
- **自动走线**：每根导线单独算出正交折线**绕开所有元件**，拐角倒圆角。拖动元件后自动重算，不会把线埋在元件底下，也不会出现「两根线看上去像接在同一个接线柱上」
- **拓扑识别**：自动判定单回路串联 / 并联 / 串并联混合，并联支路上下对齐、电源竖放居中，按教材规范排布电路图
- **实时接法检查**：悬空接线柱、元件短路、电流表并联、电压表串联、电压表直接并在电源两端、回路不闭合
- **接线柱按电位着色**：柱子的颜色跟着它所在**节点的电位**走，规则和导线完全一致 —— 于是「这根线的颜色 = 它插着的那个柱的颜色」，不用再对柱子的位置。电流表、电压表的 `+`/`−` 端与电池两极保持约定俗成的固定红黑
- **选中后可旋转**：点住悬浮工具条上的「⟳ 旋转」拖动即可（15° 一档，按住 `Shift` 微调到 1°）；双击转 90°，右侧属性里也能直接选角度
- **导出与分享**：PNG / SVG / JSON（可再导入），链接把电路编码进 `?d=`，复制即分享
- 元件库共 10 种：电池组、小灯泡、电动机、发光二极管、开关、定值电阻、滑动变阻器、电流表、电压表、保险丝，每个都有 GB/T 4728 电路图符号与实物图外观两套画法

## ⚡ 细节

- **符号线宽对齐国标**：符号按 `0.15M` 绘制，与导线的粗细一致；灯泡、电表等符号不再填成黑块，改成空心轮廓，导线直接插进符号本体
- **开关符号**改为 GB/T 4728.7「动合触点」标准画法：左端引线收在空心圆（刀闸转轴）上，刀身从圆周斜起，右端只剩固定触点引线
- **深色主题下导线不再隐形**：负极导线由写死的近黑改为跟随主题的浅灰蓝，接线柱同步
- 选中状态常驻高亮（原先只有鼠标悬停时才亮）；删除按钮紧贴导线的横段而不是甩到外接盒角落
