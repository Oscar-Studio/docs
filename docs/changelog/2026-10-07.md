# 五个站点完成百度收录优化

[主站](https://oscarstudio.cn/)、[教学工具](https://edu.oscarstudio.cn/)（[文档](/teaching-tools)）、[益智游戏集](https://games.oscarstudio.cn/)（[文档](/games)）、[实用工具](https://tools.oscarstudio.cn/)（[文档](/tools)）、[AI Studio](https://ai.oscarstudio.cn/)（[文档](/ai/AI Studio)）完成了一轮 SEO 整改，五个站均已在百度站长平台完成验证，接下来可以在后台提交抓取与 sitemap 了。

## ✨ 首页不再是爬虫眼里的空壳

之前的首页对搜索引擎来说几乎是空的：把浏览器关掉再打开[主站](https://oscarstudio.cn/)，你会发现整个页面只剩下「Oscar Studio」几个字——所有工具卡片和指向其他子站的链接，都是网页加载完之后由 JavaScript "画"上去的。百度执行 JavaScript 的能力有限，于是抓到的很可能是空页面。

现在改为**在打包时就把内容写进网页源码**：主站首页源码里直接带着 5 个子站的名称、描述和链接（此前一个链接都没有）；三个工具集首页则带上了全部 54 个工具/游戏的名称、简介和直达链接。页面由 JavaScript 接管后，这份静态内容会被自动替换掉，不会在界面上重复出现，你也不需要做任何操作。

## ✨ 54 个工具/游戏页面有了独立标题与摘要

[教学工具](https://edu.oscarstudio.cn/)、[益智游戏集](https://games.oscarstudio.cn/)、[实用工具](https://tools.oscarstudio.cn/)下的每个工具都是可以单独打开的独立页面，此前大多只有一个孤零零的标题。现在统一补齐了摘要、分享卡片和规范化链接，并且**把三种混用的标题格式统一了**：

- 教学工具：`一次函数演示 | Oscar Studio 教学工具`
- 益智游戏集：`魔方 在线玩 | Oscar Studio 益智游戏集`
- 实用工具：`字数统计 在线工具 | Oscar Studio 实用工具`

摘要内容直接取自各站已有的工具清单，不需要人工撰写。其中[编解码器](https://tools.oscarstudio.cn/codec/)的摘要原本有 123 字，超出百度展示上限会被截断在奇怪的位置，已压到 60 字。

## ✨ AI Studio 首页新增功能介绍

[AI Studio](https://ai.oscarstudio.cn/)是对话工具，用户聊的内容属于私有数据、本就不会被收录，此前页面可见文字只有界面框架。现在首屏欢迎区下方新增了一块功能介绍，讲清了三件事：[多模型对话](https://ai.oscarstudio.cn/)、Arena 并排评测多个模型的回答、语音合成与音色克隆，并说明了历史同步与额度规则。

## ✨ 新增站点地图

五个站都新增了 `sitemap.xml`（把全部可收录页面列成清单）和 `robots.txt`（指向上面的站点地图）。合计 **60 个页面**：教学工具 31、益智游戏集 16、实用工具 10、AI Studio 2、主站 1。[白板](https://tools.oscarstudio.cn/#/whiteboard)用的是 `/#/` 哈希路由、没有独立网址，已从清单中排除。

## 🐛 修掉三个指向子站的死链

[文档站](https://docs.oscarstudio.cn/)里三个"点开就能用"的按钮其实点不开，都是目录改名后文档没跟着改：

- 「句子成分分析」指向 `句子成分分析/`，实际目录叫 `英语句子成分分析/`
- 「保护色实验」指向 `camouflage/`，实际目录叫 `保护色实验/`
- 「粒子引擎」页面已随下述功能下线一并移除

现在文档站全部 58 条指向子站的链接都能正常打开。

## 🐛 下线粒子引擎与画质选项

[益智游戏集](https://games.oscarstudio.cn/)曾经有一个粒子特效模式：把画质设为 `plasma` 后，首页会由数千颗粒子组成、点击后爆散重组为游戏卡片。这套实验性代码已经停用——`oscar-quality` 这个设置项全站只有读取、**从来没有任何地方写入**，也就是说界面上根本无法开启，本次连同相关资源一并清理干净。顺带消除了 `/particle-engine/` 这个无内容目录（线上此前返回 403）。

如果你之前手动在浏览器控制台设置过这个值，清理后不会再有任何影响。
