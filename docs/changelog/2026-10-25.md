[五子棋](/games/五子棋)新增自适应引擎选择和失败回退，降低 AI 加载或运行时因设备兼容、内存不足而中断的风险。

## ⚡ 自适应选择

- 加载前检测真实 GPU adapter，不再按 iPad / Safari 等浏览器类型固定选择 CPU。
- GPU 不可用、仅有软件适配器、探测超时或出错时，使用约 11.8 MiB 的纯 CPU 引擎；GPU 可用时尝试加速引擎。
- 部分浏览器若明确报告内存不超过 2 GB，保守选择 CPU；没有内存信息时正常探测 GPU。

## 🐛 失败自动回退与内存优化

- GPU 后端初始化或推理报错时，自动保留棋谱，在新的 Worker 中使用 CPU 重试一次，避免继续使用已失败的运行环境。
- 本标签页记住回退结果，刷新后继续使用 CPU。普通下载或校验失败仍显示对应错误，不无谓下载另一套引擎。
- CPU 模式使用更轻的引擎，减少额外内存预留；推理后释放输出，大文件校验减少内存副本。
- 两种引擎继续由云存储按需下载并缓存，已有模型缓存可复用。设备仍需支持 SIMD；如果浏览器直接终止整个页面，代码无法执行自动回退。

## ⚡ 本地缓存提示

- 模型与所选 CPU / GPU 引擎均已缓存时，按钮显示「从本地加载」；部分资源已缓存时显示「下载缺失文件」，没有缓存才显示「下载模型」。
- 刷新后自动检查当前版本的缓存条目；点击加载时仍会校验文件，发现损坏才重新下载。

## ✨ 教学工具：统一数据统计

[数据统计](/teaching-tools/数据统计)合并原「数据统计」「数据统计PRO」「箱线图与分位数」，旧链接自动跳转到统一工具。

- 可独立选择频数直方图、条形统计图、折线统计图、箱线图及累计频率图，每行一个图；多组数据自动切换为复式对比。
- 直方图支持自定义组距、分组起点和频数纵轴分度值，各组共用分组边界；条形图与折线图支持原始数据或数值频数。
- 保留核心统计量表、分位数表和排序数据，箱线图支持三种须线范围。
- 图表选择和参数统一收进默认折叠的「图表设置」菜单，按需展开，减少页面占用。
