[五子棋](/games/五子棋)优化 iPad / Safari 的 AI 加载流程，降低推理引擎初始化时出现内存不足的风险。

## 🐛 修复遗留加载问题

- iPad / Safari、无 WebGPU 的设备以及手动选择 CPU 模式时，改用约 11.8 MiB 的纯 CPU 引擎，避免 CPU 对弈也加载约 25.9 MiB 的通用 GPU 引擎；其他支持 WebGPU 的浏览器继续使用原有加速路径。
- CPU 会话减少额外内存预留，推理后释放输出张量，大文件校验减少整块内存副本。
- 新引擎仍由云存储按需下载并缓存，已有模型缓存可继续复用；首次切换需要下载新 CPU 引擎一次。
- 内存不足时显示可理解的重试建议。设备仍须支持 SIMD，内存极少或浏览器自身限制仍可能导致无法运行 AI。
