# 抽签器更名幸运转盘 · 随机分组器全面重做

今天两个工具都动了：一个是**改名 + 重新定位**，一个是**彻底重做**。

## 🎡 「抽签器」更名为「幸运转盘」

[幸运转盘](https://edu.oscarstudio.cn/幸运转盘/)（[文档](/teaching-tools/幸运转盘)）原名「抽签器」，界面和文案都围着"抽人名"转。现在改名**幸运转盘**，定位改为**从任意一组选项中随机抽取一个**——选项是文字，你想放什么放什么：吃什么、玩什么、走哪条路、谁先上场、题目选哪个。

旧地址 `/抽签器/` 会自动跳转到新页面（保留书签与外链），Opilot 的旧预填参数 `namesInput` 也仍然可用。

### ✨ 选项能力

- **上限 12 → 60 项**：现在真能放下"1–20""12 个月份"这类清单
- 支持 `、` 或逗号分隔，同名自动合并
- **加权语法**：写 `红烧肉*3` 表示它的机会和扇区面积都是别人的 3 倍，转盘上直接看得出来

### ✨ 抽取方式

- 一次抽 **1 / 2 / 3 个**；抽多个时转盘停在第一个结果上，其余结果同时高亮
- **抽后移除**：抽中的选项自动离开转盘，适合"轮流点、别重复"
- **结果历史**：最近 30 次带时间记录，一键「放回转盘」（连权重一起还原）
- 6 组内置预设：是否 / 星期 / 1–20 / 月份 / 颜色 / 天气

### ⚡ 界面与交互

- 改用 **Canvas 2D** 绘制转盘，扇区按权重铺开，文字沿半径排布、左半区自动翻转避免倒读，长标签自动缩字号而不是硬截断
- 改为左右分栏工作台：左侧选项台 + 右侧转盘台，配色并入站内 Claude 设计令牌，跟随顶部按钮切换浅色 / 深色
- 转动有咔哒声、停下有和弦、结果撒彩带，三者均可单独关闭
- `Space` 快捷开转（光标在输入框里时不拦截）
- 选项与设置存在本地，刷新不丢；**分享链接**把当前选项编码进 URL，对方打开就是同一组

### 🐛 重做中修掉的问题

- **转出来的和显示的未必是同一个** — 旧实现先随机一个角度、再用公式反推下标，边界处视觉停下的扇区和文字结果可能差一格。现改为先定目标扇区再反算旋转角度，指针压在哪一格，显示的就是哪一格
- **左半边的标签跑到对面扇区去了** — 翻转文字时只转了画布角度没镜像落点，左半边的标签会画到正对面的色块上，肉眼一看就是"标签配错颜色"
- **重写选项框会丢掉权重** — 「抽后移除」和「放回转盘」都会重写文本框，只取文字的话 `甲*3` 会被拍平成 `甲`
- **每次转动都新建一个 AudioContext** — 改为全局复用一个实例

## 随机分组器全面重做

[随机分组器](https://edu.oscarstudio.cn/随机分组器/)（[文档](/teaching-tools/随机分组器)）完成了一次彻底重做。此前它只有一个名单文本框、两个会互相打架的数字框和几个按钮，分完组就只能干看着；现在换成左右分栏的工作台，并把课堂上真正会用到的那几件事补齐了。

## ✨ 多轮活动不再总是同一批人搭伙

分组轮换最怕每次都是固定的几个人凑一起。开启「**避免重复搭档**」后，重新分组会在多轮随机结果中挑选**搭档重复最少**的一轮，并在结果区显示打散百分比，鼠标悬停可以看到具体重复对数和随机基线。

需要说明的是：组数固定时零重复在数学上做不到（4 个组要完全不重复，每组最多只能各收 1 人，但实际每组需要 7~8 人）。工具会反复重排去逼近最优，30 人分 4 组的实测下限约 14 对重复。

## ✨ 锁定分组，只洗剩下的

某一组不想被打散？点组卡上的锁图标锁定，之后的「重新分组」只会重排**其余未锁定**的成员，锁定组原封不动。锁定的组也不能被拖走或清空，会提示先解锁。

## ⚡ 名单怎么贴都行

- 逗号、顿号、分号、制表符、换行混排分隔都能识别，从表格里直接复制粘贴也可以
- **自动去重**（忽略大小写），并明确告诉你去掉了几个重复项
- 支持从 `.txt` / `.csv` 文件导入，或一键载入 30 人示例名单
- 名单与结果自动存在本地，刷新页面不丢

## ✨ 分完还能改

- **拖拽**成员即可在组间调整；**待分配池里的成员也能直接拖回任意组**
- 拖起来时所有可放置区域（各组 + 待分配池）会同时描出虚线框，鼠标扫过去当前落点高亮，锁定的组不参与高亮
- **点选移动**（触屏友好）：点一下成员选中，再点目标组即可移动
- 点成员上的 `×` 移入「待分配」池，或整组清空；「全部归队」一键放回
- **组名可点击直接改**——改成「红队」「1 号桌」这类课堂用语
- 结果不对可以撤销（`Ctrl / ⌘ + Z`）

## ⚡ 导出

- 复制单组名单 / 复制全部
- 导出 **TXT**（带生成时间）与 **CSV**（含 BOM，Excel 直接打开不乱码）
- **打印**：自动隐藏操作区，只留分组结果

## ⚡ 界面与随机质量

- 改用站内统一的 Claude 设计配色，每组一个主题色（8 色循环），跟随顶部主题按钮切换浅色 / 深色
- 随机改用 `crypto.getRandomValues` 做无偏取样的 Fisher–Yates 洗牌，不再用 `Math.random`
- 原来的两个数字框换成**分段切换 + 步进器 + 滑块**，上下限随名单人数自动调整，不会出现「分 12 组但只有 8 个人」
- 错误提示从浏览器原生 `alert()` 换成页面内吐司
- 快捷键：`Ctrl / ⌘ + Enter` 立即分组，`Esc` 取消选中

## 🐛 顺带修掉的重做中发现的 bug

- **待分配池里的人拖不进组** — 拖拽事件只挂在分组结果区上，从池子里起拖拿不到拖拽中的成员名，池 → 组这个方向完全拖不动（组 → 池却正常，方向正好反了），待分配池等于只能进不能出
- **触屏够不到移除按钮** — 成员上的 `×` 原本靠 `opacity: 0` 在悬停时显示，手机和平板上没有悬停，等于永远点不到。现改为只在真正能悬停的设备上隐藏
- **清空后再撤销会复活旧分组** — 撤销会把一份与当前名单对不上的结果捞回来，出现"名单 8 人 / 结果 30 人"
- **待分配池形同虚设** — 重新分组时，池子里的人被悄悄并回名单，本轮照样参与分组
- **锁定组能被清空** — 拖动成员时有锁定校验，清空整组却没有；拖入锁定组也不设防
- **总人数漏算待分配** — 统计条只算已分组的人，待分配人数不计入
- **零值提示常驻** — 重复数、待分配数在 0 时仍然显示；结果区提示行因为同时用了两种显示控制方式而一直不出现
