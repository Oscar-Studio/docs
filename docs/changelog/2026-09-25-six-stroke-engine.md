# 六冲程汽油机工作循环模拟器上线

[教学工具集](/teaching-tools/six-stroke-engine) 新增 **六冲程汽油机工作循环模拟器**，把传统四冲程之外的"两次正功"循环用动图完整画出来。

## ✨ 新增

- **机构可视化**：曲柄-连杆-活塞与飞轮同步动画，行程 2r 标注、冷却水路与 H₂O 喷射模块独立可显隐
- **完整六冲程演示**：进气 → 压缩 → 燃烧做功 → 排气 → 冷却水进气 → 蒸汽排气，每个冲程显示运动区间、阀门状态、活塞方向
- **实时参数面板**：实时仿真 / 周期计数（CYCLES）、曲轴转角（θ°，三转一轮回）、REV 2/3 标记
- **仪表盘**：缸压、工质温度、缸壁温度、相对容积随曲轴转角实时更新
- **教学交互**：暂停 / 复位 / 上一冲程 / 下一冲程 / ±5° 微调，800–6000 r/min 仿真速度可调

## ⚡ 实现细节

- React + SVG 单页应用，单文件部署（261 KB，含全部 React runtime 与 Tailwind 样式）
- 跟随 edu 站点主题切换（浅色 / 深色 / 跟随系统），与既有工具共享顶部头与返回入口
- 隶属"物理"学科分类，标签：动画 · 热机 · 物理 · 仿真
