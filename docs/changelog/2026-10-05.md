# 心算记忆支持完整键盘操作

[心算记忆](https://games.oscarstudio.cn/心算记忆/)（[文档](/games/心算记忆)）现在**全程可以只用键盘**玩，不用在鼠标和键盘之间来回换手。游戏界面底部新增了一条快捷键提示，开始页的帮助说明里也写上了这几个键。

## ⚡ 快捷键

| 按键 | 作用 |
| --- | --- |
| `0`–`9` | 输入答案 |
| `Enter` | 下一题 |
| `Backspace` | 退格 |
| `Delete` | 清空 |
| `Esc` | 放弃本局 |

在**开始页**和**结算页**按 `Enter` 或空格可以直接开始 / 再来一局，不用先去点按钮。

敲物理键盘时，屏幕上对应的数字键会**跟着闪一下**——不然纯键盘操作时反馈全在输入框里，很容易以为按键没生效。

## 🐛 修掉几个会让键盘不好用的地方

这次不是从零加键盘支持（原来就有），而是修掉了其中几个真实的问题：

- **鼠标点过数字键后再按 `Enter` 会触发两次**：点击后焦点留在按钮上，`Enter` 既进下一题、又把那个数字输进答案框。现在点击后立即交出焦点。
- **`Esc` 的语义反了**：原来 `Esc` 是"清空输入"，但界面上「放弃」按钮没有快捷键，很容易误触丢一整局。现在 **`Esc` = 放弃本局**（带确认框），清空改用 `Delete`。
- **数字键判定不可靠**：原来靠字符串比较判断是不是数字键，改成正则匹配。
- **开始页和结算页按键盘毫无反应**：现在这两个界面也支持 `Enter` 快速开始。
- 顺带修了一个 CSS 变量遗漏：倒计时进入警戒状态时引用的 `--accent-amber` 一直没定义，那个琥珀色警告其实没生效过。现在正常显示了。
