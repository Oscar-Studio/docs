## 隐私说明

| 工具 | 数据去向 |
|------|----------|
| 正则表达式工作台、图片压缩器、编解码器、密码生成器、二维码生成器、字数统计、Markdown 编辑器 | 全部在浏览器本地处理，**不发起任何上传请求** |
| 颜文字大全 | 分类浏览与字面搜索纯本地；**语义搜索**会把查询词发到自有服务器调 embedding 接口，仅用于本次相似度计算，不落库、不用于训练 |
| 待办清单、白板 | 未登录时存本地；登录后同步到你的账号（游客则按访客身份存储） |

所有工具都支持浅色 / 深色主题切换，并跟随系统的 `prefers-color-scheme` 初始偏好。
