# 课堂倒计时器

专为课堂场景设计的倒计时工具。用一只**会翻转、会流沙的沙漏**表示剩余时间，配色随剩余比例逐级升温，配有适合投影的**专注模式**。

## 沙漏怎么表示时间

页面中央是一只沙漏，外围一圈进度环，两者严格同源。三种状态都按真实沙漏的物理绘制：

- **待机**：一只静止的沙漏 —— 沙已漏尽，堆在下壶的**玻璃底板**上，上壶是空的。
- **点开始**：整只沙漏 180° 翻转。那堆沙随之转到上方，于是从**漏斗颈口**开始下落。
- **计时中**：下壶的沙从玻璃底板**往上堆成锥形**，堆面随时间升高；上壶那堆**坐在颈口**逐渐下沉，退到颈口时正好漏尽。沙量即剩余时间。
- **结束**：沙全部落尽，数字与沙漏一起转绿。

暂停时沙流冻结在原地（而不是消失），一恢复就接着流。

沙堆位置的交换被安排在翻转过程中旋转最快、剪影最窄的那一帧，且此刻沙量恰好是满的、新旧两种画法填满同一区间，因此看不出接缝。

## 功能特性

- **四段配色** — 珊瑚 → 琥珀（剩余 ≤ 25%）→ 危险红并脉动（≤ 10%）→ 完成绿。暂停在最后几秒时仍保留告警色。
- **最长 10 小时** — 超过 1 小时读数自动补出小时位，格式变为 `10:00:00` 并自动降一档字号。
- **读数两侧微调** — `▲ 加 1 分` / `▼ 减 1 分` 夹在大号读数的上下两侧，按住可连续走。**只在待机时可用**：运行中改总长会让"沙量 = 剩余时间"当场失效。
- **专注模式（`F`）** — 隐藏全部界面、字号放大、强制深色，适合投影到大屏；`Esc` 退出。
- **快捷预设** — `30 秒` / `1 分` / `2 分` / `3 分` / `5 分` / `8 分` / `10 分` / `15 分` / `20 分`，另提供 10 秒 ~ 10 小时的连续滑块。
- **课堂任务标签** — 填入"限时答题 · 第 3 题"这类文字，显示在标题位置，方便投屏时说明当前环节。
- **结束提示音** — 5 种音色（铃声 / 风铃 / 提示音 / 水滴 / 电子音）全部用 Web Audio 实时合成，不下载任何音频文件，可试听。
- **最后 10 秒滴答** — 可选的每秒轻响，便于全班同步答题节奏。
- **屏幕常亮** — 计时时申请 Wake Lock，避免投影设备自动息屏（浏览器支持时生效）。
- **深浅主题** — 跟随教学工具站的主题切换。

## 使用步骤

1. 打开页面，点预设、拖动滑块，或用读数上下的 `▲ / ▼` 微调（10 秒 ~ 10 小时）
2. 点「开始」，沙漏翻转后开始流沙
3. 「暂停」冻结沙流；「重置」把沙收回下壶底板
4. 进入专注模式投屏，或直接用「全屏显示」
5. 时间归零播放提示音 + 震动 + 系统通知（需授予通知权限）

## 快捷键

| 键位 | 作用 |
|---|---|
| `Space` / `K` | 开始 / 暂停切换 |
| `R` | 重置 |
| `F` | 专注模式 |
| `↑` / `↓` | ±1 分钟（待机时） |
| `Shift` + `↑` / `↓` | ±10 秒（待机时） |
| `Esc` | 退出专注模式 |

设置项（任务标签、时长、音色、滴答、常亮）保存在浏览器 `localStorage`，下次打开自动恢复。

## 技术实现

- **纯静态** — HTML + CSS + 原生 JavaScript，单文件可运行
- **SVG 沙漏** — 玻璃、木框、沙堆、落沙流全部为 SVG 图形。沙堆由同一个生成器 `heapPath(lo, hi, fill)` 描述：基底固定在 `lo`、朝 `hi` 方向堆出 `fill` 的高度，堆面中间微微隆起，方向自动跟随 `lo`/`hi` 的大小关系
- **rAF 主循环** — 以 `performance.now()` 时间戳为准，不依赖 `setInterval` 计数，因此后台标签页节流后也不会累积漂移；进度环与沙面无级平滑
- **Web Audio API** — 5 种结束音与滴答音均由 `OscillatorNode` 实时合成，含指数衰减包络
- **Wake Lock API** — 计时期间保持屏幕常亮，暂停或结束时释放
- **无障碍** — 尊重 `prefers-reduced-motion`（关闭翻转、落沙与脉动动画），状态变化经 `aria-live` 播报

- 演讲 / 面试 / 活动环节控制
