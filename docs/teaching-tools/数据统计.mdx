# 数据统计

「数据统计」「数据统计PRO」「箱线图与分位数」现已合并为一个工具。输入一组或多组数据，自由选择图表，统一查看核心统计量与分位数。

<PillButton href="https://edu.oscarstudio.cn/数据统计/" variant="primary">打开数据统计 →</PillButton>

## 使用方法

1. 在输入框中输入一组数字，支持空格、中英文逗号、分号、换行，也支持负数、小数和科学计数法。
2. 点击「添加数据组」增加其他组，可修改组名或移除组。空白组不参与统计。
3. 按需展开默认收起的「图表设置」菜单，选择图表类型、组距等参数，然后点击「开始统计」。也可以载入两组示例。
4. 修改图表设置会立即更新图表；修改数据后需重新点击「开始统计」。

## 可选图表

所有图表每行显示一个，多组数据自动切换为复式对比，使用相同坐标轴。

| 图表 | 设置与含义 |
|---|---|
| 频数直方图 | 支持自动或自定义组距（横轴分度值）、分组起点、频数纵轴分度值。各组使用相同区间，左闭右开，最后一个区间包含右端点 |
| 条形统计图 | 按输入顺序展示原始值，或合并相同数值展示频数；多组并列 |
| 折线统计图 | 按输入顺序展示原始值，或按数值从小到大展示频数；多组折线对比 |
| 箱线图 | 可选择 1.5 倍四分位距内的实际值、最小/最大值、3%/97% 分位数作为须线，须线外数值显示为散点 |
| 累计频率图 | 展示不大于当前数值的数据比例，多组阶梯曲线对比 |

例如，输入 0、5、10、15、20，设置起点 0、组距 10，区间为 `[0, 10)` 和 `[10, 20]`，对应频数为 2 和 3。起点不能大于最小值，组距必须大于 0。

取消所有图表勾选后，仍可查看两张统计表和排序数据。

## 保留的统计表

- **核心统计量**：个数、平均数、中位数、众数、极差、离差平方和、方差、标准差。方差按总体计算（除以 n）；所有值只出现一次时显示「无众数」，并列众数全部列出。
- **分位数**：Min、3%、5%、10%、25%、50%、75%、90%、95%、97%、Max。
- **排序数据**：展开「查看排序后的数据」即可查看每组升序数据；原始顺序图仍使用输入顺序。

分位数采用位置 `(n−1) × p` 的线性插值；箱体下沿、中线、上沿分别与表内 25%、50%、75% 分位数一致。结果最多显示 6 位小数，极小值以科学计数法展示。
