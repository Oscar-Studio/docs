# 数据统计

轻量级数据统计分析工具——输入一组数值即可自动计算**平均数、离散平方和、方差、标准差**并绘制带平均值参考线的柱状图。

## 功能特性

- **四种核心统计量** — 平均数、离散平方和、方差、标准差
- **多格式输入** — 支持逗号、空格、换行分隔数值
- **柱状图可视化** — 直观展示每个数据点
- **平均值参考线** — 折线叠加，方便对比
- **数据列表回显** — 显示所有已解析的数据点
- **输入校验** — 无效数据提示且不会崩溃
- **响应式布局** — 桌面 / 移动端自适应

## 使用步骤

1. 打开页面，默认已填入示例 `10, 15, 20, 25, 30`
2. 在输入框中编辑数据（用逗号 / 空格 / 换行分隔）
3. 点击"计算统计量"按钮
4. 查看下方四个统计量卡片与柱状图
5. 至少需要 **2 个**有效数据点

## 计算公式

| 统计量 | 公式 |
|---|---|
| 平均数 | `x̄ = Σxᵢ / n` |
| 离散平方和 | `SS = Σ(xᵢ − x̄)²` |
| 方差 | `s² = SS / n` |
| 标准差 | `s = √(s²)` |

## 输入格式示例

```
10, 15, 20, 25, 30
```

或

```
10 15 20 25 30
```

或混用

```
10,
15
20 25, 30
```

## 技术实现

- **Chart.js** — 柱状图 + 折线参考线
- **正则分割** — `/[\s,]+/` 同时支持逗号、空格、换行
- **实时校验** — `parseFloat` 失败时给出明确错误信息
- **纯静态** — 无后端依赖，开箱即用

## 适用场景

- 高中数学"随机抽样"、"用样本估计总体"章节
- 课堂演示离散程度统计量
- 学生作业数据快速处理
