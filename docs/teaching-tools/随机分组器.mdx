# 随机分组器

把任意名单随机分成若干组——按组数均衡分，或按每组人数固定分。除了"一键随机"，还补上了课堂上真正用得上的环节：**多轮活动避免重复搭档**、**锁定分组重新洗其余的人**、**拖拽手动微调**和**导出名单**。

## 功能特性

### 名单处理

- 每行一个名字，也支持**逗号、顿号、分号、制表符**混排分隔（从表格里直接复制粘贴也能用）
- **自动去重**，忽略大小写，并明确提示去掉了几个重复项
- 实时人数统计与名单预览
- 支持**导入文件**（`.txt` / `.csv`），或一键载入 30 人示例名单
- 名单和结果自动存在本地，刷新页面不丢

### 分组方式

| 模式 | 行为 | 适用场景 |
|---|---|---|
| **按组数分** | 分成 N 组，组内人数差不超过 1 | "给我分 6 组" |
| **按每组人数** | 每组 K 人，组数自动计算 | "每组 5 个人" |

两种模式下的人数上限都会随名单自动调整，避免"分 12 组但只有 8 个人"这类无效输入。

### 避免重复搭档

课堂活动常要分组轮换，如果每次都是同一批人搭伙，体验就打折了。开启「避免重复搭档」后，重新分组会在多轮随机结果中**挑选搭档重复最少的一轮**，并在结果区显示打散百分比（鼠标悬停可看具体重复对数与随机基线）。

:::note 这里的"打散"是尽力而为
组数固定时，数学上不可能做到零重复（4 个组最多只能各收 1 人才能完全不重复，但每组需要 7~8 人）。工具会反复重排去逼近最优，30 人分 4 组的实测下限约 14 对重复。
:::

### 锁定分组

不想让某一组被打散？点组卡上的锁图标锁定它，之后的「重新分组」只会重排**其余未锁定**的成员，锁定组原封不动。锁定的组也不能被拖走或清空，会提示先解锁。

### 手动微调

- **拖拽**：把成员直接拖到别的组
- **点选移动**（触屏友好）：点一下成员选中，再点目标组即可移动
- 点成员上的 **×** 移入「待分配」池，或清空整组
- 组名可点击直接改成「红队」「1 号桌」这类课堂用语

### 导出

- 复制单组名单 / 复制全部
- 导出 **TXT**（带生成时间）与 **CSV**（含 BOM，Excel 直接打开不乱码）
- **打印**：自带打印样式，自动隐藏操作区，只留分组结果

### 界面

- 沿用站内 Claude 设计令牌，跟随顶部主题按钮切换**浅色 / 深色**
- 每组一个主题色（8 色循环），深浅两种模式下都能分辨
- 尊重系统 `prefers-reduced-motion` 动效偏好

## 使用步骤

1. 粘贴名单（每行一个），或点「导入名单」读取文件
2. 选择分组方式，用步进器或滑块设定组数 / 每组人数
3. 点「开始分组」（或按 `Ctrl + Enter`）
4. 需要微调就拖拽成员；要换一轮就点「重新分组」
5. 满意后复制 / 导出 / 打印

## 快捷键

| 键位 | 作用 |
|---|---|
| `Ctrl / ⌘ + Enter` | 立即分组 / 重新分组 |
| `Ctrl / ⌘ + Z` | 撤销上一次操作 |
| `Esc` | 取消「选中待移动」的成员 |

## 技术实现

- **纯静态** — HTML + CSS + 原生 JavaScript，无构建、无依赖
- **公平随机** — `crypto.getRandomValues` 做拒绝采样得到无偏整数，再跑 Fisher–Yates；比 `Math.random` 更适合"要公平"的场合
- **均衡分配** — 洗牌后轮转填充（round-robin），保证各组人数差 ≤ 1
- **重复度优化** — 用组内两两搭档的哈希集合算重复数，最多重排 150 次取最优
- **无 `alert()`** — 全部改用吐司提示
- **响应式** — 桌面端左右工作台，移动端单栏堆叠

## 适用场景

- 课堂小组活动随机分组、讨论课分组
- 多轮活动的搭档轮换（避免总是同几个人一组）
- 团队建设、破冰活动
- 任何需要将一群人随机拆分、并且要能导出名单的场景
