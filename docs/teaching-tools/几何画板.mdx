# 几何画板

一块可以随手画、并且能**一键构造**标准图形的交互式画板。画好任意图形后，中点、垂线、平行线、角平分线、三角形的高/中线/角平分线/中位线、外接圆、内切圆、四心等辅助线与特殊点都能自动生成——用来做课堂演示、探究「为什么」和快速出题配图。

## 基本图形

支持绘制以下基础对象：

- **点 / 线段 / 射线 / 直线**
- **圆**
- **多边形**（下拉直接提供 **等腰三角形、等边三角形、平行四边形、矩形、菱形、正方形**）

## 一键构造

选中图形后可自动生成：

| 类别 | 可构造对象 |
| --- | --- |
| 中点类 | 中点、中线、中位线 |
| 垂直类 | 垂线 |
| 平行类 | 平行线 |
| 角平分线 | 三角形的角平分线 |
| 高 | 三角形的高 |
| 圆 | 外接圆、内切圆 |
| 四心 | 重心、垂心、外心、内心 |

## 导出与分享

- **PNG** — 直接导出位图，适合贴进课件或作业
- **SVG** — 矢量导出，放大不糊，适合印刷与二次编辑
- **JSON** — 导出图形数据，便于保存 / 复用
- **可分享链接** — 当前画板状态可编码进 URL，发给别人就能打开同一张图

## 编辑操作

- **撤销 / 重做** — 误操作可回退
- **删除** — 移除选中对象
- **清空** — 一键重置画板

## 适用场景

- 平面几何课堂：现场画图 + 自动生成辅助线，演示「中位线定理」「四心关系」这类结论
- 作业讲解：学生提交的手绘稿，用标准图形重画一遍做对比
- 探究活动：先自由画，再一键构造，让学生自己发现规律

## 提示

构造类命令依赖选中对象——先点选目标图形，再点构造命令，才能正确生成辅助线与特殊点。
