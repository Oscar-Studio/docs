# 科学计算器

功能完整的网页科学计算器，涵盖基础运算与科学运算，支持三角函数、对数、阶乘、键盘输入。

## 功能特性

- **基础运算** — 加减乘除、括号、百分号
- **三角函数** — `sin` / `cos` / `tan` 及对应的反三角函数
- **对数与指数** — `log` / `ln` / `e^x` / `10^x` / `^`
- **阶乘** — `n!` 与排列组合
- **幂运算** — `x^y` / `√` / `∛`
- **键盘输入** — 数字键直接输入，运算符对应物理键位

## 使用步骤

1. 打开页面，默认进入计算器界面
2. 用鼠标点击按钮或直接用键盘输入表达式
3. 按 `Enter` 或 `=` 键求值
4. 历史记录会自动保存在本地存储

## 快捷键

| 键位 | 作用 |
|---|---|
| `0-9` | 输入数字 |
| `+ - * /` | 四则运算 |
| `( )` | 括号 |
| `.` | 小数点 |
| `Enter` / `=` | 求值 |
| `Backspace` | 删除最后一个字符 |
| `Esc` | 清除当前输入 |

## 技术实现

- **纯静态** — HTML + CSS + 原生 JavaScript，无任何依赖
- **单文件** — 整个计算器在单一 `index.html` 中，可离线运行
- **本地存储** — 使用 `localStorage` 持久化历史记录

## 适用场景

- 数学课堂演示
- 学生日常作业辅助
- 物理 / 化学 / 生物课程的快速计算
