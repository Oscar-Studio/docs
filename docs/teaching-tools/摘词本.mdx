# 摘词本

英语单词录入 → 背诵 → 复习的完整闭环：基于 **FSRS**（Free Spaced Repetition Scheduler）算法自适应安排复习间隔，每个词按自身稳定性（stability）独立调度，并提供「未学习 / 学习中 / 已掌握」三种状态筛选。

## 四大功能

- **✏️ 录入** — 输入英文 + 中文释义，一键加入云端词本
- **📖 总览** — 按状态（未学习 / 学习中 / 已掌握）和排序（新→旧 / 旧→新 / 字母）筛选
- **🎯 背诵** — 看中文写英文，答对后从 Again/Hard/Good/Easy 4 档评级，FSRS 据此推算下次复习时间
- **🧠 复习** — 智能列出「到期的」单词，答错则重置次数并立即拉回 24 小时后再考

## 使用步骤

1. 登录后进入主菜单，点击 **录入** 添加单词
2. 在 **总览** 中可按状态 / 字母 / 时间排序浏览
3. 每日打开 **背诵** 完成设置数量的生词（默认 10 个，可在 ⚙ 设置中修改 1-50）
4. 隔天打开 **复习**，系统自动列出到期需要复习的旧词

## FSRS 自适应调度

每个词独立追踪两个核心参数：

- **稳定性 S（stability）** — 这个词你能记多久（天数）
- **难度 D（difficulty）** — 这个词对你有多难（0~10）

每次复习后 FSRS 会根据你的评级（Again/Hard/Good/Easy）更新 S 和 D，并按目标可提取性（默认 90%）反推下次该什么时候复习。

| 评级 | 含义 | 对稳定性的影响 |
|---|---|---|
| Again (1) | 完全忘了 | 大幅缩短，下次很快再考 |
| Hard (2) | 答对但很勉强 | 微缩短 |
| Good (3) | 正常答对 | 按公式推算 |
| Easy (4) | 答对且轻松 | 大幅拉长 |

**「已掌握」判定**：当一个词的状态进入 `Review` 且稳定性 S ≥ 365 天（≈ 1 年长期记忆）时自动标记为 `mastered`，不再加入复习队列。简单词可能 5 次掌握，困难词可能要 10+ 次——这正是自适应相对固定间隔的核心优势。

## 技术实现

- **后端 API** — `https://api.oscarstudio.cn/api/wordbook`（CRUD + Bearer 鉴权）
- **复习调度** — 前端按 `next_review` 时间戳与当前时间比较，过期即入队
- **本地存储** — `localStorage.wordbook_settings` 保存每日背诵数量
- **数据字段** — `word` / `translation` / `status` / `review_count` / `last_review` / `next_review` / `difficulty` / `stability` / `fsrs_state` / `lapses`

## 适用场景

- 高中 / 大学英语日常单词积累
- 备考四六级、雅思、托福的滚动复习
- 任何需要长期记忆的英文词汇训练
