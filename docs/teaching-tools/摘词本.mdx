# 摘词本

英语单词录入 → 背诵 → 复习的完整闭环：基于 **FSRS**（Free Spaced Repetition Scheduler）算法自适应安排复习间隔，每个词按自身稳定性（stability）独立调度，并提供「未学习 / 学习中 / 已掌握」三种状态筛选。

## 使用步骤

1. 登录后打开摘词本，点击 **录入词条**，填入英文单词、短语或词块及中文释义。添加例句时，可以选中实际文本作为挖空内容，并填写整句翻译。
2. 在 **我的词库** 搜索英文或中文释义，按学习状态筛选，或按时间和字母排序。每条记录旁可打开例句编辑和删除操作。
3. 在 **今日学习** 选择 **到期复习** 或 **背诵新词**。每次练习只看一道题。新词默认每组 10 条，可在 **学习设置** 中调整为 1 到 50 条。
4. 输入英文并检查答案，再按记忆情况评级。「自适应」模式下，答错自动记为「忘记」。例句题接受词条原形和挖空的词形，可查看首字母提示。保存失败时，可在当前题点 **重试保存**。

## FSRS 自适应调度

每个词独立追踪两个核心参数：

- **稳定性 S（stability）** — 这个词你能记多久（天数）
- **难度 D（difficulty）** — 这个词对你有多难（0~10）

每次复习后 FSRS 会根据你的评级（Again/Hard/Good/Easy）更新 S 和 D，并按目标记忆保持率（默认 90%）反推下次该什么时候复习。

| 评级 | 含义 |
|---|---|
| Again (1) | 完全忘了 |
| Hard (2) | 答对但很勉强 |
| Good (3) | 正常答对 |
| Easy (4) | 答对且轻松 |

**「已掌握」判定**：当一个词的状态进入 `Review` 且稳定性 S ≥ 365 天（≈ 1 年长期记忆）时自动标记为 `mastered`，不再加入复习队列。简单词可能 5 次掌握，困难词可能要 10+ 次——这正是自适应相对固定间隔的核心优势。

## 技术实现

- **后端 API** — `https://api.oscarstudio.cn/api/wordbook`（CRUD + Bearer 鉴权）
- **复习调度** — 前端按 `next_review` 时间戳与当前时间比较，过期即入队
- **本地存储** — `localStorage.wordbook_settings` 保存每组新词数量、目标记忆保持率与评级方式
- **数据字段** — `word` / `translation` / `status` / `review_count` / `last_review` / `next_review` / `difficulty` / `stability` / `fsrs_state` / `lapses`

## 适用场景

- 高中 / 大学英语日常单词积累
- 备考四六级、雅思、托福的滚动复习
- 任何需要长期记忆的英文词汇训练
