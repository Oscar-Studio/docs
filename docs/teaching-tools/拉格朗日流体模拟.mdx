# 拉格朗日流体模拟

基于 **SPH（光滑粒子流体动力学）** 的流体演示。拉格朗日视角下，物理量挂在一个个**粒子**上——你能直接看到「一堆粒子聚成水团、撞上障碍、飞溅散开」，这正是它和欧拉网格视角最直观的区别。

## 场景

| 场景 | 适合演示 |
| --- | --- |
| **溃坝** | 经典 benchmark，水柱崩塌推进，自由表面翻卷 |
| **水滴** | 单滴水在重力下成球、坠落、铺开 |
| **石子入水** | 固体入水的下沉与溅射 |
| **对撞** | 两股水流相向运动的冲击 |
| **方块下落** | 流体中的浮力现象 |
| **倾倒（杯→杯）** | 连续流动与液面变化 |
| **漏斗** | 收敛流动，粒子向出口汇聚 |

## 可调参数

- **粒子数** — 精度与性能的直接权衡
- **平滑半径**（h）— 核函数作用范围，影响表面张力感与聚团程度
- **气体常数** 与 **粘度** — 决定流体的「稀薄 / 黏稠」手感
- **重力** — 控制下落与溃坝的速度感
- **模拟速度** — 连续 / 分步切换

## 连续模拟 vs 分步模拟

- **连续模拟** — 粒子持续演化，适合观察动态过程
- **分步模拟** — 一步一步推进；此时会把**力向量直接画成箭头**，能看清每个粒子受什么力、往哪走

分步模式是理解 SPH 数值过程最直观的方式：力 → 加速度 → 位置更新的每一步都在画面上留痕。

## 与欧拉版的区别

| 维度 | 拉格朗日（SPH） | 欧拉（MAC + Projection） |
| --- | --- | --- |
| 描述对象 | 一个个粒子 | 一个个格点 |
| 物理量挂在哪 | 粒子上 | 网格上 |
| 「水」长什么样 | 一堆粒子 | 染料浓度场 + 矢量箭头 |
| 边界 / 障碍 | 粒子碰撞 + 接触约束 | 格点标成 solid，u = v = 0 |
| 难点 | 邻居搜索、核函数、聚团 | 压力泊松方程的迭代收敛 |
| 适合 | 自由表面、飞溅、溃坝 | 大尺度流体、内部压力场、绕障流 |

同站另有 [欧拉流体模拟](/teaching-tools/欧拉流体模拟)，两者可对照讲解「同一道方程，两种数值方法」。

## 适用场景

- 流体力学入门：建立「流体由粒子构成」的直观图像
- 数值方法：观察粒子数、平滑半径对稳定性与精度的影响
- 与欧拉版对照：同一道方程两种数值方法的差异
