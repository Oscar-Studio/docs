# 智能点名器

简单好用的课堂随机点名工具——名单快速生成 / 导入，两种模式：随机点名 / 不重复点名，结果自动朗读。

## 功能特性

- **名单生成** — 输入学生人数自动生成「`1 号` … `N 号`」名单
- **名单导入** — 支持上传 `.txt` 文件，每行一个名字，自动替换为真实姓名
- **可选名单** — 勾选框控制每位学生是否参与本次点名，可全选 / 取消全选
- **随机点名** — 完全随机，每次都可能抽到同一个人
- **不重复点名** — 抽过的学生不再出现，直到本轮所有人抽完
- **TTS 朗读** — 抽中后自动朗读「`张三` 被抽中了」
- **滚动动画** — 老虎机式名字滚动 + 模糊效果，停止时弹出高亮结果

## 使用步骤

1. 打开页面，默认生成 40 名学生名单
2. 可修改学生人数后点「生成列表」，或点「导入名单」上传 `.txt`
3. 通过复选框取消不希望参与点名的学生
4. 选择模式 —— 🎲 随机点名 或 🚫 不重复点名
5. 在新页面点击「开始」，名字快速滚动 1.5 – 3 秒后自动停止并朗读
6. 不重复模式下抽完一轮后点「再来一轮」即可重置

## 快捷键

| 键位 | 作用 |
|---|---|
| 点击「开始」 | 启动一次点名滚动 |
| 点击「再来一轮」 | 仅在不重复模式抽完后出现，重置候选池 |

## 技术实现

- **纯静态** — HTML + CSS + 原生 JavaScript，无任何依赖
- **Web Speech API** — 通过 `SpeechSynthesisUtterance` + `zh-CN` 实现中文朗读
- **老虎机动画** — CSS `@keyframes blurText` + `transform: scale()` 实现流畅滚动
- **Fisher–Yates 思路** — 不重复模式通过从候选池移除已抽中的学生实现

## 适用场景

- 课堂提问随机抽人
- 小组活动公平分工
- 任何需要随机选取的场景
