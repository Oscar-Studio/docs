# 幸运转盘

把**任何一组选项**丢进转盘，随机转出一个结果——课堂提问、活动安排、决定顺序、随手做个小决定都行。它不预设"抽人"场景：选项是文字，你想放什么放什么。

## 功能特性

### 选项怎么写

- 每行一个选项，也支持用 `、` 或逗号分隔
- 最多 **60 项**（旧版只支持 12 项）
- 同名自动合并，标签过长自动截断

### 加权：让某些选项机会更大

在选项后面加 `*数字` 就是权重：

```
红烧肉*3
清蒸鱼
麻辣香锅*2
```

`红烧肉` 的扇区面积和被抽中的概率都是别人的 **3 倍**，转盘上能直接看出来。权重上限 99，同名项的权重会累加。

### 一次抽几个

可选 **1 / 2 / 3 个**。抽多个时转盘停在**第一个**结果上，其余结果在转盘上同时高亮，结果卡片并排展示。

### 抽后移除

开启后，抽中的选项自动离开转盘，适合"轮流点、别重复"的游戏。抽空的选项可以在下方**历史记录**里一键「放回转盘」（连权重一起还原）。

:::note 没开这个开关就没有「放回转盘」
选项没被移走过，放回去没有意义，所以这个按钮只在**那一轮真的移除过选项**时才出现——按每条记录判断，而不是看当前开关状态。
:::

### 结果与历史

- 结果卡片按转盘配色展示，一键复制
- 最近 30 次抽取记录，带时间，可放回
- 音效（转动咔哒 + 停下和弦）与彩带庆祝都可单独关闭

### 其它

- **6 组内置预设**：是否 / 星期 / 1–20 / 月份 / 颜色 / 天气
- **分享链接**：把当前选项编码进 URL，对方打开就是同一组选项
- **本地记忆**：选项和设置存在 `localStorage`，刷新不丢
- **快捷键**：`Space` 开转（光标在输入框里时不拦截）

## 使用步骤

1. 在左侧文本框里每行写一个选项（或点"快速填入"用预设）
2. 选好每次抽几个，按需打开「抽后移除」
3. 点转盘中央的**开始**按钮（或按 `Space`）
4. 转盘停下后，结果卡片显示抽中的选项，可复制或再转一次

## 技术实现

- **纯静态单文件** — HTML + CSS + 原生 JavaScript，无任何依赖
- **Canvas 2D 绘制转盘** — 按权重把选项铺成扇区，文字沿半径排布、左半区自动翻转避免倒读，长标签自动缩字号
- **`requestAnimationFrame` 驱动动画** — 长尾缓动 + 末尾阻尼抖动，落位角度精确
- **结果由最终角度反推** — 先定目标扇区再算旋转角度，指针压在哪一格，显示的就是哪一格（这是旧版最大的坑：随机角度再反推下标，视觉与文案可能对不上）
- **Web Audio API** — 音效由 `OscillatorNode` 合成，`AudioContext` 全局复用一次
- **双主题** — 跟随 `_shared/design-tokens.css`，浅色下"画板"是深色块、深色下反转为米色，切换主题时重绘 Canvas

## 适用场景

- 课堂随机提问、活动分组、活动顺序安排
- 决定谁先上场、谁负责哪一环节
- 随手做个小决定：吃什么、玩什么、走哪条路
- 抽签决定惩罚与奖励、做游戏抽卡

## 注意事项

- 权重只影响**概率和扇区面积**，不影响绝对公平性；仍由 `Math.random()` 驱动
- 选项存在浏览器本地，换设备或清缓存后需要重新填写（或用分享链接带上）
