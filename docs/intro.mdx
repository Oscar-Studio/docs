## 关于本站

本站是 Oscar Studio 所有工具 / 游戏 / AI 应用的统一文档入口。每个产品都有自己的详情页：

- 左侧侧边栏按 **教学工具 / 益智游戏 / AI** 三个分类展开
- 每个产品详情页含功能说明、使用步骤、技术实现
- 顶栏搜索框可全文搜索（基于本地索引）

产品本体部署在独立的子域名：

| 域名 | 内容 |
|---|---|
| [tools.oscarstudio.cn](https://tools.oscarstudio.cn) | 教学工具 |
| [games.oscarstudio.cn](https://games.oscarstudio.cn) | 益智游戏 |
| [ai.oscarstudio.cn](https://ai.oscarstudio.cn) | AI Studio |
| [api.oscarstudio.cn](https://api.oscarstudio.cn) | 后端 API |
| [blog.oscarstudio.cn](https://blog.oscarstudio.cn) | 博客 |

## 设计语言

本站采用 xAI 风格设计——

- **纯黑底** `#0a0a0a` 与白色文字对比
- **Inter** 字体（display / body）+ **JetBrains Mono** 字体（eyebrow / labels）
- **Pill 按钮** 9999px 圆角，1px 白色半透明描边
- **Hairline 边框** `#212327` 替代阴影

详细设计 tokens 见 `xai-design/DESIGN.md`。
