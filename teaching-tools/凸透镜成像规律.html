凸透镜成像规律

交互式凸透镜成像演示——调节焦距、物距、物高，实时观察像距、像高、放大率、成像性质与三条特殊光线的传播路径。

Try it →View source

功能特性​

  • 三参数滑块联动 — 焦距 f、物距 u、物高 h
  • 数值输入框 — 滑块与数字输入双向绑定
  • 实时计算像参数 — 像距 v、像高 h'、放大率 m、成像性质
  • 三条特殊光线追踪 — 平行光、过光心、过焦点
  • 实像 / 虚像可视化 — 虚像用虚线 + 正立箭头区分
  • u = f 边界情况 — 像在无穷远时明确标注
  • 焦点 F 与 2F 标记 — 红色与绿色圆点对照

使用步骤​

  1. 打开页面，默认参数：焦距 100、物距 200、物高 50
  2. 拖动滑块或直接输入数值调整 f / u / h
  3. 观察右侧信息面板四个参数实时变化
  4. 画布上观察物、像、镜、焦点、特殊光线的变化
  5. 重点实验 u = f、u = 2f、物距小于焦距等边界情况

参数范围​

参数范围单位含义
焦距 f50 ~ 200px凸透镜中心到焦点的距离
物距 u30 ~ 400px物体到透镜中心的距离
物高 h20 ~ 100px物体（向上箭头）高度

核心公式​

1/f = 1/u + 1/v
m = v/u = h'/h
  • f — 焦距
  • u — 物距
  • v — 像距（v < 0 表示虚像）
  • m — 放大率（绝对值）
  • h / h' — 物高 / 像高

成像性质对照​

物距 u成像性质
u < f正立放大虚像（放大镜原理）
u = f不成像（像在无穷远）
f < u < 2f倒立放大实像（投影仪原理）
u = 2f倒立等大实像
u > 2f倒立缩小实像（照相机原理）

三条特殊光线​

  1. 平行于主光轴 → 折射后过右侧焦点 F
  2. 过光心 → 传播方向不变
  3. 过左侧焦点 F → 折射后平行于主光轴射出

技术实现​

  • Canvas 2D — 坐标系、光线、物体、像、焦点绘制
  • SVG 透镜 — 渐变填充模拟玻璃质感
  • 滑块 + 数字框 — 双向事件同步
  • 边界判断 — 自动识别实像 / 虚像 / 无穷远情况

适用场景​

  • 初中物理"凸透镜成像规律"教学演示
  • 探究物距变化对像的性质影响
  • 照相机 / 投影仪 / 放大镜原理直观展示
