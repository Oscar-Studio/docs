一次函数演示

交互式函数图像演示工具，支持一次函数 y = kx + b 与二次函数 y = ax² + bx + c 两种模式，通过滑块实时调参观察图像、关键点与判别式的变化。

Try it →View source

功能特性​

  • 双模式切换 — 一次函数 y = kx + b 与二次函数 y = ax² + bx + c 一键切换
  • 滑块实时调参 — 系数变化即时反映在函数图像与关键点上
  • 关键点高亮 — 一次函数显示斜率、截距、与 x/y 轴交点；二次函数额外显示顶点、对称轴、判别式
  • 二次函数智能分析 — 自动判别 Δ = b² − 4ac，给出实根个数与位置
  • 对称轴可视化 — 二次函数模式下自动绘制对称轴虚线与顶点圆点
  • 一键重置 — 快速回到默认参数

使用步骤​

  1. 打开页面，默认进入一次函数模式
  2. 用顶部按钮切换模式：一次函数 y = kx + b / 二次函数 y = ax² + bx + c
  3. 拖动右侧滑块调整 k / b（一次）或 a / b / c（二次）
  4. 观察左侧 Canvas 图像、函数表达式与关键点卡片实时变化
  5. 点击"重置为默认值"恢复初始参数

参数说明​

一次函数 y = kx + b​

滑块范围步长作用
斜率 k−3 ~ 30.1直线倾斜程度，正负决定递增/递减
截距 b−5 ~ 50.1直线与 y 轴交点（x=0 时 y=b）

二次函数 y = ax² + bx + c​

滑块范围步长作用
二次项 a−2 ~ 20.1决定开口方向（a>0 向上）与宽窄
一次项 b−5 ~ 50.1影响对称轴位置 x = −b/(2a)
常数项 c−5 ~ 50.1抛物线与 y 轴交点 (0, c)

技术实现​

  • 纯静态 — HTML + CSS + 原生 JavaScript + Canvas 2D，无任何依赖
  • Canvas 网格 — 自绘坐标系、刻度与函数曲线
  • 实时渲染 — 滑块 input 事件触发重绘，零延迟
  • 判别式分析 — 自动计算 Δ = b² − 4ac 判断二次函数与 x 轴交点情况

适用场景​

  • 初中数学"一次函数"课堂演示
  • 高中数学"二次函数"图像与性质教学
  • 探究斜率、截距、二次项系数对图像的影响
  • 直观理解判别式与实根个数的关系
